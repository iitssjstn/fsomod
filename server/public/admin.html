Twitch-app

  1. Ga naar dev.twitch.tv/console/apps → Register Your Application.
  2. OAuth Redirect URL:
  3. Categorie Game Integration, client type Confidential.
  4. Vul hieronder de Client ID en een nieuw Client Secret in.

Contact (openbaar)

Dit adres staat op /privacy en /terms. Gebruik hetzelfde adres als het Support Email bij Twitch. Leeg laten = er staat een verwijzing naar het support-adres in de Twitch-extensielijst.

Twitch-extensie (bits met één klik)

  1. Maak op dev.twitch.tv/console/extensions een extensie aan. Kies bij Extension Types: Panel en Video - Fullscreen.
  2. Bij Asset Hosting: Panel Viewer Path panel.html (hoogte 500), Video Fullscreen Viewer Path video_overlay.html, Config Path config.html.
  3. Bij Capabilities: zet Allowlist for URL Fetching Domains op . Bij Monetization: Bits enabled.
  4. Vul hieronder de sleutels van de extensie in (bij Extension Settings → Client ID, Extension Secret en Client Secret) en klik op Opslaan.
  5. Klik op Koppelen & prijzen bijwerken: de server meldt zich aan voor betalingen en zet de bits-producten klaar.
  6. Download de zip hieronder en upload hem bij Files → Upload Version. Zet de extensie in Hosted Test en installeer hem op het kanaal.
Geheimen worden nooit getoond. Laat leeg om ze te houden.
